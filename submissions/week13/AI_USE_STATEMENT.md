# AI Use Statement — Week 13

**Team:** NutriChat · **Checkpoint:** `w13-final` · **Date:** 2026-11-15

OpenAI Codex assisted development and provided suggestions, including code,
debugging, tests, reference-recipe drafting and documentation. Qwen/HKUST interpret
meal descriptions at runtime; Python calculates nutrients from versioned data.
The offline demo uses a deterministic fixture, not a generative model.

Codex-assisted automated, API and browser checks are documented in the
[final verification record](../../docs/evidence/week13-verification.md), including
failed attempts and remaining limitations. Findings led to food-matching fixes,
stronger review guards and clearer interface guidance. These records describe
assistant-run checks, not an independent team rehearsal.

The team defined the scope and rejected image-based estimation. Unsupported-food
substitution and model-generated nutrient totals are excluded. The team remains
responsible for reviewing, understanding and submitting the work.
