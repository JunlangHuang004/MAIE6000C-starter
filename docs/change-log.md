# NutriChat change log

## 2026-10-17 — 中餐食物库、双模式估算与追问对话

### 用户可见改动

- 新增基础版：按用户描述快速估算，未提供重量时采用可见的参考份量，
  支持碗／个／份数量；展示所有默认配方与用油假设。
- 新增进阶版：逐项补充可食重量、生熟状态、做法、实际摄入油量；
  中餐配方的食材克数和整锅成品重量可编辑并确认。
- 同一条未确认记录可以切换模式。基础版的默认值不会被保存成用户事实。
- 千问解析中文、多轮补充和更正；营养数值由数据查表和程序计算。
- 116 种 USDA SR Legacy 食材，带 CC0 许可、FDC 编号、生熟状态和中文别名。
- 50 道项目自建中餐参考配方，非实测或标准菜谱；所有营养由 USDA 食材计算。
- 保存对话、追问、配方及计算依据，刷新后可恢复；完成后仍须核对确认。
- 未匹配食物、矛盾的生熟状态和做法不会产生捏造的营养结果。

### 同批提交包含的前序功能

- 千问中国区配置与连接检查、异步营养分析、修改重算和版本冲突保护。
- 中文页面、普通网页登录、签名会话 Cookie；登录配置通过私有环境文件加载。
- ECS / Docker Compose 部署配置、Nginx HTTPS 反向代理和证书续期脚本。
- 无密钥演示模式保留原有严格英文克数输入，用于离线测试。

### 数据库与运维

- 0003：修改版本号、确认时间、解析结果。
- 0004：对话、结构化草稿、待追问问题、营养依据、用户可见错误信息。
- 0005：基础／进阶模式。
- 新字段对旧记录有默认值，不删除已有餐食或用户数据。
- 数据来源、导入复现、接口和限制见 `nutrition-data.md`。
- API Key、登录密码、服务器环境文件、证书及数据库备份不进入 Git。

### 验证

- 59 项单元／集成测试通过；Ruff 检查及页面 JavaScript 语法检查通过。
- 真实千问请求验证基础版份量估计和进阶追问。
- 浏览器验证配方编辑、模式切换、结果展示和刷新恢复。
- 香港 ECS 上的真实千问流程已通过：基础估算 → 进阶追问 → 配方编辑 →
  自然语言更正 → 确认保存；测试餐食从参考 365.2 kcal 调整为 264.7 kcal。
