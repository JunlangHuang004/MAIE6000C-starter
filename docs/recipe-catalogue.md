# NutriChat dish index

350 project-authored home-style reference recipes. One reference per dish; alternative names share the same ID. This is a coverage list, not a popularity ranking or a collection of measured nutrition values. Chinese names and method descriptions match the application.

All ingredient grams, retained oil and finished batch weights are editable assumptions. In advanced mode, users must review them before calculation. Seafood and meat weights exclude shells, bones and other inedible parts. Basic defaults do not become user-supplied facts.

See [nutrition data](nutrition-data.md) for provenance, limitations and rebuilding the catalogue. The maintained source is `services/common/data/recipes.json`.
